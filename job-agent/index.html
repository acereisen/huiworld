一个本地优先的 Python 求职 Agent：自动采集职位、匹配个人技能、去重并生成申请草稿。最终投递始终由你确认。

查看 GitHub 源码 ↗快速开始 ↓
01 / DISCOVER

职位采集

支持示例数据和 Adzuna Jobs API，并可继续扩展合规的公开数据源。

02 / MATCH

智能匹配

综合目标职位、技能、地点和排除词评分，高匹配岗位优先展示。

03 / REVIEW

人工确认

生成个性化申请草稿，但不会绕过验证码、登录网站或未经确认自动投递。
